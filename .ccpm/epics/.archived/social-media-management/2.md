## Context

Toàn hệ thống hiện chỉ có 2 role (`ADMIN`, `USER`). Đội vận hành thực tế có 2 nhóm khác biệt: vài Admin toàn quyền và nhiều Content Moderator chỉ cần quyền hạn chế (Posts + Report, không đụng Users). `MODERATOR` phải tồn tại trong `Constants.USER_ROLE` trước — mọi task khác (middleware Be, route-guard Fe, LoginPage) đều phụ thuộc giá trị này. `Breads-Shared` là git submodule dùng chung 3 repo (`Breads-Admin`, `Breads-Fe`, `Breads-Be`) — đổi sai chỗ hoặc bump lệch SHA sẽ khiến 3 repo hiểu giá trị role khác nhau.

## Description

Thêm `MODERATOR: 2` vào object `Constants.USER_ROLE` trong repo `Breads-Shared` (đường dẫn thật khi đứng từ `Breads-Admin`: `../Breads-Shared` là repo riêng, KHÔNG sửa qua `src/Breads-Shared` của từng repo con — sửa ở đó không merge lên upstream). Sau khi merge, bump submodule pointer ở cả 3 repo con.

## Implementation Steps

1. Trong repo `Breads-Shared` (không phải qua submodule path của repo con), mở `Constants/index.ts`, thêm dòng `MODERATOR: 2,` vào object `USER_ROLE` (hiện có `ADMIN: 0, USER: 1`). Giữ nguyên format/style hiện có (class-based static field).
2. Commit + push lên `Breads-Shared` (nhánh chính hoặc theo quy trình review riêng của repo đó nếu có).
3. Ở `Breads-Admin`: `cd src/Breads-Shared && git checkout <sha-mới> && cd ../.. && git add src/Breads-Shared && git commit -m "chore: bump Breads-Shared submodule (MODERATOR role)"`.
4. Lặp lại bước 3 cho `Breads-Fe` và `Breads-Be` (đường dẫn submodule trong 2 repo đó cũng là `src/Breads-Shared` theo cấu trúc hiện có).
5. Verify: `git submodule status` ở cả 3 repo phải trả về **cùng 1 SHA**.

## Acceptance Criteria

- **FR-4 / scenario:** GIVEN thay đổi đã merge vào `Breads-Shared`, WHEN chạy `git submodule status` ở `Breads-Admin`, `Breads-Fe`, `Breads-Be`, THEN cả 3 lệnh trả về cùng 1 SHA và SHA đó chứa dòng `MODERATOR: 2`.
- **FR-4 / scenario:** GIVEN submodule đã bump, WHEN import `Constants` từ `@/Breads-Shared/Constants` trong bất kỳ file nào của 3 repo, THEN `Constants.USER_ROLE.MODERATOR === 2` không lỗi type/runtime.
