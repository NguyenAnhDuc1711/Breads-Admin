## Context

`Breads-Admin` hiện chỉ có `App.tsx` với `<Routes>` phẳng (`/login`, `/users`), không có nơi điều hướng chung. Hệ thống quản trị mạng xã hội Breads có 5 khu vực (Overview, Posts, Posts Validation, Report, Users) nhưng 4/5 chưa có route nào — cần khung layout+routing đủ chỗ cho cả 5, dù nội dung 4 khu vực còn lại (ngoài scope epic này) sẽ được xây ở epic sau.

## Description

Tạo `AdminLayout` (sidebar tĩnh 5 mục + `<Outlet/>`, **chưa có role-guard** — guard thêm ở task riêng T5/012 vì phụ thuộc role Moderator từ 001). Sửa `App.tsx` để route lồng nhau dưới `AdminLayout`, 4 route mới trỏ placeholder đơn giản. Route `/` phải đổi từ redirect-sang-`/users` hiện tại thành mount Overview placeholder (xem Implementation Steps bước 4 — bắt buộc, nếu bỏ qua Overview sẽ không bao giờ hiển thị).

## Implementation Steps

1. Tạo `src/layouts/AdminLayout.tsx`: component nhận không props, render `<div>` gồm 1 `<nav>`/sidebar liệt kê 5 `<Link>` (dùng `react-router-dom`) tới `/` (Overview), `/posts`, `/posts/validation`, `/report`, `/users`, và 1 vùng nội dung chứa `<Outlet/>`. Style tối giản bằng Bootstrap class sẵn có (dự án đã dùng Bootstrap ở `UsersPage.tsx`), không cần CSS module mới trừ khi cần.
2. Tạo 4 component placeholder tối giản (có thể inline trong `AdminLayout.tsx` hoặc file riêng `src/pages/ComingSoonPage.tsx` nhận `title` prop) — hiển thị tiêu đề khu vực + dòng chữ rõ ràng kiểu "Khu vực này đang được xây dựng."
3. Trong `src/App.tsx`: import `AdminLayout`, bọc route con bằng `<Route element={<AdminLayout/>}>` chứa 5 `<Route>`: `path="/"` → Overview placeholder, `path="/posts"` → Posts placeholder, `path="/posts/validation"` → Posts Validation placeholder, `path="/report"` → Report placeholder, `path="/users"` → `UsersPage` (giữ nguyên, không đổi).
4. **Bắt buộc xoá dòng `<Route path="/" element={<Navigate to="/users" replace />} />` hiện có trong `App.tsx`** — nếu không xoá, `/` tiếp tục redirect sang `/users` và Overview placeholder ở bước 3 không bao giờ render (phát hiện từ plan-review ARCH-1).
5. Giữ nguyên `<Route path="/login" element={<LoginPage/>}/>` — route login KHÔNG nằm trong `AdminLayout` (không cần sidebar khi chưa đăng nhập).

## Acceptance Criteria

- **FR-1 / scenario:** GIVEN đã đăng nhập (bất kỳ trạng thái nào — guard theo role chưa có ở task này), WHEN vào Breads-Admin, THEN sidebar hiển thị đủ 5 mục điều hướng, mỗi mục dẫn đúng route.
- **FR-2 / scenario:** GIVEN vào route `/`, WHEN trang load, THEN thấy Overview placeholder (KHÔNG redirect sang `/users`).
- **FR-2 / scenario:** GIVEN vào `/posts`, `/posts/validation`, hoặc `/report`, WHEN trang load, THEN thấy placeholder ghi rõ khu vực đang chờ triển khai — không phải trang trắng, không phải lỗi 404.
- **FR-2 / scenario:** GIVEN vào `/users`, WHEN trang load, THEN `UsersPage` hiển thị y hệt trước khi có `AdminLayout` (route path không đổi).

## Technical Details

`App.tsx` hiện tại:
```tsx
<Routes>
  <Route path="/" element={<Navigate to="/users" replace />} />
  <Route path="/login" element={<LoginPage />} />
  <Route path="/users" element={<UsersPage />} />
</Routes>
```
Sau thay đổi, cấu trúc dự kiến:
```tsx
<Routes>
  <Route path="/login" element={<LoginPage />} />
  <Route element={<AdminLayout />}>
    <Route path="/" element={<OverviewPlaceholder />} />
    <Route path="/posts" element={<ComingSoonPage title="Posts" />} />
    <Route path="/posts/validation" element={<ComingSoonPage title="Posts Validation" />} />
    <Route path="/report" element={<ComingSoonPage title="Report" />} />
    <Route path="/users" element={<UsersPage />} />
  </Route>
</Routes>
```
Tham khảo pattern gate tương tự (không copy logic, chỉ tham khảo cấu trúc) ở `../Breads-Fe/app/(main)/admin/layout.tsx`.
